# LoopStop

Public landing page and privacy policy for **LoopStop**, an Android screen-time tool that interrupts endless scrolling in Instagram, TikTok, and YouTube Shorts.

- [Live landing page](https://itaycohen-prog.github.io/loopstop/)
- [Privacy policy](https://itaycohen-prog.github.io/loopstop/privacy-policy.html)

LoopStop performs its detection locally on the device. The app requests no network permission and includes no analytics, advertising, tracking, or third-party SDKs.

This repository intentionally contains only the static public website and privacy-policy files.
